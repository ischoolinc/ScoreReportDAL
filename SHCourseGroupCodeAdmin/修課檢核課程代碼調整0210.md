# 修課檢核課程代碼調整0210

## 修改日期
2026-02-10

## 目的
- 在 `chkGPlanInfo` 解析課程規劃表科目時，新增蒐集「特殊需求領域」科目的清單：`SubjectSpecNameList`
- 條件：當 `科目屬性 == "特殊需求領域"`，將該科目的 **科目名稱+級別 key**（`SubjectName + "_" + Level`）加入清單

---

## 變更內容

### 修改檔案
- `DAO/chkGPlanInfo.cs`

### 新增欄位
在 `chkGPlanInfo` 類別中新增：
```csharp
// 特殊需求領域：科目名稱_級別(key) 清單
public List<string> SubjectSpecNameList = new List<string>();
```

**位置**：靠近既有的 `SubjectNameList` 定義處（行 36 之後）

---

## 實作方式

### 1. 初始化清單
在 `ParseSubjectDict()` 方法進入點，清空所有清單時加入：
```csharp
SubjectSpecNameList.Clear();
```

**位置**：與 `SubjectXMLDict.Clear()`, `SubjectDict.Clear()`, `SubjectNameList.Clear()` 一起（行 42-44）

### 2. 解析特殊需求領域科目
在 `foreach (XElement elm in ContentXML.Elements("Subject"))` 迴圈內：

1. 取得科目名稱與級別（維持現有邏輯）
2. 組合 key：`key = SubjectName + "_" + Level`
3. 讀取科目屬性：`elm.Attribute("科目屬性")?.Value ?? ""`
4. 若等於 `"特殊需求領域"`：
   - 若 `SubjectSpecNameList` 不含該 key，則加入

**實作要點**：
- 使用 null-safe 存取：`elm.Attribute("科目屬性")?.Value ?? ""`
- 去重：`if (!SubjectSpecNameList.Contains(key)) SubjectSpecNameList.Add(key);`
- 位置：放在建立 `key` 後、寫入 `SubjectXMLDict` 前（行 59 之後）

**程式碼片段**：
```csharp
string key = SubjectName + "_" + Level;

// 檢查是否為特殊需求領域
string subjectAttribute = elm.Attribute("科目屬性")?.Value ?? "";
if (subjectAttribute == "特殊需求領域")
{
    if (!SubjectSpecNameList.Contains(key))
        SubjectSpecNameList.Add(key);
}

if (!SubjectXMLDict.ContainsKey(key))
    SubjectXMLDict.Add(key, elm);
```

## 行為規格

### SubjectSpecNameList 內容
- **格式**：`SubjectName_Level`（與 `SubjectDict` 的 key 格式一致）
- **內容**：僅包含 `科目屬性 == "特殊需求領域"` 的科目
- **去重**：相同 key 不會重複加入

### 解析規則
- 當 `elm.Attribute("科目屬性")?.Value == "特殊需求領域"` → 加入 key
- 當 `科目屬性` 不存在或為其他值 → 不加入
- 重複呼叫 `ParseSubjectDict()` 不會累積舊資料（會先 Clear）

## 分組名稱解析（追加）

### 新增欄位
在 `chkGPlanInfo` 類別中新增：
```csharp
// 分組科目：Key=分組名稱，Value=科目名稱_級別(key) 清單
public Dictionary<string, List<string>> SubjectGroupDict = new Dictionary<string, List<string>>();
```

**位置**：靠近 `SubjectSpecNameList` 定義處（行 39 之後）

### 實作方式

#### 1. 初始化 Dict
在 `ParseSubjectDict()` 方法進入點，清空所有清單時加入：
```csharp
SubjectGroupDict.Clear();
```

**位置**：與其他 Clear() 一起（行 48）

#### 2. 解析分組名稱
在 `foreach (XElement elm in ContentXML.Elements("Subject"))` 迴圈內，產生 `key` 之後：

1. 讀取分組名稱：`elm.Attribute("分組名稱")?.Value ?? ""`
2. 若 `!string.IsNullOrWhiteSpace(groupName)`：
   - 若 Dict 沒有該 key，先建立 `new List<string>()`
   - 將 `key` 加入 List（需去重）

**程式碼片段**：
```csharp
string key = SubjectName + "_" + Level;

// 檢查分組名稱
string groupName = elm.Attribute("分組名稱")?.Value ?? "";
if (!string.IsNullOrWhiteSpace(groupName))
{
    if (!SubjectGroupDict.ContainsKey(groupName))
        SubjectGroupDict.Add(groupName, new List<string>());

    if (!SubjectGroupDict[groupName].Contains(key))
        SubjectGroupDict[groupName].Add(key);
}
```

### 行為規格

#### SubjectGroupDict 內容
- **Key**：分組名稱（`分組名稱` 屬性值，不為空/空白）
- **Value**：`List<string>`，內容為 `SubjectName_Level`（與 `SubjectDict` 的 key 格式一致）
- **去重**：同一分組內的 key 不會重複

#### 解析規則
- 當 `分組名稱` 有值且不為空白 → 建立/加入分組清單
- 當 `分組名稱` 為空/空白或不存在 → 不處理
- 重複呼叫 `ParseSubjectDict()` 不會累積舊資料（會先 Clear）

### 測試

#### 測試案例
準備最小 XML：

**測試資料**：
- **Subject A**：
  - `分組名稱="分組A"`
  - `SubjectName="國語文"`
  - `Level="1"`
  - 預期：`SubjectGroupDict["分組A"]` 含 `"國語文_1"`

- **Subject B**：
  - `分組名稱="分組A"`
  - `SubjectName="英文"`
  - `Level="2"`
  - 預期：`SubjectGroupDict["分組A"]` 含 `"國語文_1"`、`"英文_2"`

- **Subject C**：
  - `分組名稱=""` 或不含 `分組名稱`
  - `SubjectName="數學"`
  - `Level="1"`
  - 預期：不會出現在任何分組中

#### 測試流程
1. 建立 `chkGPlanInfo`，設定 `ContentXML`
2. 呼叫 `ParseSubjectDict()`
3. 驗證：
   - `SubjectGroupDict` 含 Key `"分組A"`
   - `SubjectGroupDict["分組A"]` 含 `"國語文_1"`、`"英文_2"`
   - 不會出現空的分組 key
   - 重複呼叫 `ParseSubjectDict()` 不會重複累加

### 使用方式
其他程式碼可以透過以下方式使用：
```csharp
chkGPlanInfo gplan = ...;
gplan.ParseSubjectDict();

// 取得某分組的所有科目
string groupName = "分組A";
if (gplan.SubjectGroupDict.ContainsKey(groupName))
{
    List<string> subjectsInGroup = gplan.SubjectGroupDict[groupName];
    // 處理分組內的科目
}
```

## 注意事項

1. **key 格式一致性**：`SubjectSpecNameList` 和 `SubjectGroupDict` 中的 key 格式與 `SubjectDict` 的 key 格式一致（`SubjectName_Level`），方便後續比對使用
2. **null-safe 存取**：使用 `?.Value ?? ""` 避免當屬性不存在時發生例外
3. **去重機制**：使用 `Contains` 檢查避免重複加入相同 key
4. **清空機制**：每次呼叫 `ParseSubjectDict()` 時會先清空所有清單/Dict，確保不會累積舊資料
5. **分組名稱過濾**：只有 `分組名稱` 有值且不為空白時才會加入 Dict，避免出現空字串 key
