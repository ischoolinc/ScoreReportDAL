## Todo 2：_bgWorker_DoWork 新增取得 dc_bind_key 對應筆數

### 需求
- 資料表：`dc_bind_key`
- 欄位：`ref_course_id`
- 傳入：多筆課程編號（`_SelectIDList`）
- 回傳：各課程對應筆數（未取得預設 -1）
- 需快取供後續刪除階段判斷：`_CourseBindCountDict`、`_HasCourseBindData`

### 建議插入位置
在「取得課程ID與名稱」之後、或在取得 `sc_attend` 之前/之後皆可（建議放在 `ReportProgress(50)` 前後，依你目前 UI 進度設計調整）。

### 程式碼（直接套用）

```csharp
// 取得課程調代課對應資料
_CourseBindCountDict.Clear();
_HasCourseBindData = false;

try
{
    string bindSQL = @"
        SELECT ref_course_id, COUNT(*) AS cnt
        FROM dc_bind_key
        WHERE ref_course_id IN (" + string.Join(",", _SelectIDList.ToArray()) + @")
        GROUP BY ref_course_id;
    ";

    DataTable dtBind = qh.Select(bindSQL);

    // 預設 -1（未取得）
    foreach (string cid in _SelectIDList)
        _CourseBindCountDict[cid] = -1;

    if (dtBind != null)
    {
        foreach (DataRow dr in dtBind.Rows)
        {
            string cid = dr["ref_course_id"].ToString();
            int cnt = Convert.ToInt32(dr["cnt"]);

            _CourseBindCountDict[cid] = cnt;
            if (cnt > 0)
                _HasCourseBindData = true;
        }
    }
}
catch (Exception ex)
{
    Console.WriteLine("取得課程調代課對應資料失敗：" + ex.Message);
}
```

## Todo 3：_bgWorkerDel_DoWork 刪除 dc_bind_key（並寫入刪除筆數 log）

### 刪除順序（關鍵）
在既有刪除流程開始前（最前面），先處理：

1. 取得預計刪除筆數（count）
2. 刪除 `dc_bind_key`
3. 寫入 `ApplicationLog`（若 count > 0）

### 3.1 取得預計刪除筆數（僅當 _HasCourseBindData）

將以下程式放在 `_bgWorkerDel_DoWork` 一開始（在任何 DELETE 前）：

```csharp
int delBindCount = 0;

if (_HasCourseBindData)
{
    try
    {
        QueryHelper qh = new QueryHelper();
        string countSQL = @"
            SELECT COUNT(*)
            FROM dc_bind_key
            WHERE ref_course_id IN (" + string.Join(",", _SelectIDList.ToArray()) + ")";
        DataTable dt = qh.Select(countSQL);

        if (dt != null && dt.Rows.Count > 0)
            delBindCount = Convert.ToInt32(dt.Rows[0][0]);
    }
    catch (Exception ex)
    {
        Console.WriteLine("取得調代課刪除筆數失敗," + ex.Message);
    }
}
```

### 3.2 刪除 dc_bind_key（僅當 _HasCourseBindData）

接續在上段之後：

```csharp
if (_HasCourseBindData)
{
    try
    {
        string delBindSQL = @"
            DELETE FROM dc_bind_key
            WHERE ref_course_id IN (" + string.Join(",", _SelectIDList.ToArray()) + ")";
        uh.Execute(delBindSQL);
    }
    catch (Exception ex)
    {
        Console.WriteLine("刪除課程調代課對應資料失敗," + ex.Message);
    }
}
```

### 3.3 ApplicationLog 記錄刪除筆數（delBindCount > 0 才記錄）

接續在刪除 dc_bind_key 後、刪除 sce_take 前（或緊接在刪除 dc_bind_key 後即可）：

```csharp
if (delBindCount > 0)
{
    StringBuilder sbBind = new StringBuilder();
    sbBind.AppendLine("刪除課程調代課對應資料(dc_bind_key)：");
    sbBind.AppendLine("刪除筆數：" + delBindCount);

    ApplicationLog.Log("課程.刪除課程與修課學生", sbBind.ToString());
}
```
