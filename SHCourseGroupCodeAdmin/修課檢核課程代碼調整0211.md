## 實作方式

### 策略：O(1) 查詢
在每位學生（sid）開始檢核前，準備 3 個查表結構：

1. **subjectKeyToGroupMap**：`SubjectName_SubjectLevel -> groupName`
   - 型別：`Dictionary<string, string>`
   - 來源：`chkGPlanInfoDict[graduation_plan_id].SubjectGroupDict`

2. **courseCodeToSubjectKeyMap**：`CourseCode -> SubjectName_SubjectLevel`
   - 型別：`Dictionary<string, string>`
   - 來源：`chkGPlanInfoDict[graduation_plan_id].SubjectDict`

3. **passedGroupSet**：學生已通過的群組集合（只要任一科修到即可通過）
   - 型別：`HashSet<string>`
   - 來源：學生已修課程代碼 + `courseCodeToSubjectKeyMap` + `subjectKeyToGroupMap`

---

## 具體實作步驟

### Step 1：建立 subjectKeyToGroupMap
在確認 `chkGPlanInfoDict.ContainsKey(graduation_plan_id)` 後、開始檢查前加入：

```csharp
var subjectKeyToGroupMap = new Dictionary<string, string>(StringComparer.Ordinal);
var subjectGroupDict = chkGPlanInfoDict[graduation_plan_id].SubjectGroupDict;

if (subjectGroupDict != null)
{
    foreach (var g in subjectGroupDict)
    {
        string groupName = g.Key ?? "";
        if (g.Value == null) continue;

        foreach (var subjectKey in g.Value)
        {
            if (string.IsNullOrWhiteSpace(subjectKey)) continue;

            // 若同一 subjectKey 出現在多個 group：先採用第一個（避免不確定性擴散）
            if (!subjectKeyToGroupMap.ContainsKey(subjectKey))
                subjectKeyToGroupMap.Add(subjectKey, groupName);
        }
    }
}
```

**注意**：若同一 subjectKey 出現在多個 group，先採用第一個，避免規劃表資料品質問題造成檢核結果飄移。

---

### Step 2：建立 courseCodeToSubjectKeyMap
以課程規劃表 `SubjectDict` 為基礎：

```csharp
var courseCodeToSubjectKeyMap = new Dictionary<string, string>(StringComparer.Ordinal);

foreach (string key in chkGPlanInfoDict[graduation_plan_id].SubjectDict.Keys)
{
    var s = chkGPlanInfoDict[graduation_plan_id].SubjectDict[key];
    if (s == null) continue;

    string cc = (s.CourseCode ?? "").Trim();
    if (cc == "") continue;

    string subjName = (s.SubjectName ?? "").Trim();
    string subjLevel = (s.SubjectLevel ?? "").Trim();
    string subjectKey = subjName + "_" + subjLevel;

    // 同一 CourseCode 重複：先採用第一個
    if (!courseCodeToSubjectKeyMap.ContainsKey(cc))
        courseCodeToSubjectKeyMap.Add(cc, subjectKey);
}
```

---

### Step 3：計算該學生 passedGroupSet
在「檢查學生應修課程代碼未修」迴圈之前加入：

```csharp
var passedGroupSet = new HashSet<string>(StringComparer.Ordinal);
var studentSubjectKeySet = new HashSet<string>(StringComparer.Ordinal);

// 依學生已修課程代碼 → 推導出 SubjectName_SubjectLevel keys
if (chkHasCourseCodeDict.ContainsKey(sid))
{
    foreach (var cc in chkHasCourseCodeDict[sid])
    {
        string courseCode = (cc ?? "").Trim();
        if (courseCode == "") continue;

        if (courseCodeToSubjectKeyMap.TryGetValue(courseCode, out string sk)
            && !string.IsNullOrWhiteSpace(sk))
        {
            studentSubjectKeySet.Add(sk);
        }
    }
}

// subjectKey 若存在於 group，代表該 group 通過
foreach (var sk in studentSubjectKeySet)
{
    if (subjectKeyToGroupMap.TryGetValue(sk, out string groupName)
        && !string.IsNullOrWhiteSpace(groupName))
    {
        passedGroupSet.Add(groupName);
    }
}
```

---

### Step 4：在 foreach 迴圈中加入「群組 continue」判斷
在原本的 `foreach (chkGPSubjectInfo subj in thisCousreCodeList)` 內，「課程代碼判斷」之前插入：

```csharp
// ===== 群組判斷（同組任一科已修 → 同組其他科 continue）=====
string subjName = (subj.SubjectName ?? "").Trim();
string subjLevel = (subj.SubjectLevel ?? "").Trim();
string subjectKey = subjName + "_" + subjLevel;

if (subjectKeyToGroupMap.TryGetValue(subjectKey, out string groupName)
    && !string.IsNullOrWhiteSpace(groupName))
{
    if (passedGroupSet.Contains(groupName))
        continue;
}
// ===== 群組判斷 End =====
```

然後保留原本的單科 CourseCode 判斷：

```csharp
// 有課程代碼
if (chkHasCourseCodeDict.ContainsKey(sid))
{
    if (chkHasCourseCodeDict[sid].Contains(subj.CourseCode))
        continue;
}
```

## 行為規格

### 群組判斷規則
- **科目屬於某 group**：若 group 已通過（同組任一科已修）→ 直接 continue（不會列為未修）
- **科目不屬於任何 group**：維持原本 CourseCode 判斷（不影響既有行為）

### 判斷順序
1. 先檢查群組判斷（若通過則 continue）
2. 再檢查單科 CourseCode 判斷（若通過則 continue）
3. 都不通過才加入未修清單

---

## 測試案例

### Case 1：同組已修一科
- **Group**：`自然群` 包含 `物理_1` / `化學_1` / `生物_1`
- **學生已修**：`物理_1`
- **預期**：`化學_1` / `生物_1` 不應加入未修清單（continue）

### Case 2：同組都未修
- **Group**：同上 group
- **學生未修**：任何一科
- **預期**：該學期應開課的 group 內科目仍會各自被判定未修（加入清單）

### Case 3：科目不在任何 group
- **預期**：完全沿用原本 CourseCode 邏輯，不應有變動

## 效能考量

### O(1) 查詢設計
- 使用 `Dictionary` 和 `HashSet` 實現 O(1) 查詢
- 查表結構在每位學生開始檢核前建立一次，可重用
- 避免在迴圈內重複查詢資料庫或遍歷清單

### 記憶體使用
- 查表結構僅在 `_bgWorker_DoWork` 方法內宣告使用，避免影響其他程式
- 每位學生處理完後，查表結構可被 GC 回收（若需要）

## 注意事項

1. **查表結構建立時機**：在每位學生開始檢核前建立，每個 `graduation_plan_id` 可重用
2. **群組判斷優先順序**：先檢查群組判斷，再檢查單科 CourseCode 判斷
3. **去重機制**：使用 `HashSet` 確保群組和科目 key 不重複
4. **null-safe 處理**：所有屬性存取都使用 null-safe 方式，避免例外
5. **字串比對**：使用 `StringComparer.Ordinal` 確保比對一致性
