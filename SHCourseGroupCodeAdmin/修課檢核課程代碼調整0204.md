## 行為規格

### TryParseCredit 方法規格
- **輸入**：`object value`（可能為 string、null、空白等）
- **輸出**：`bool`（是否成功轉換）+ `out double credit`（轉換後的數值）
- **處理邏輯**：
  - `null / 空白 / 只有空白字元` → 回傳 `false`（不轉換）
  - 可解析數字（含小數）→ 回傳 `true` 並輸出 `double`
  - 不可解析（例如：`"-"`, `"N/A"`）→ 回傳 `false`（保持空白，不丟例外）

### 寫入 Excel 邏輯
- **可解析為數值**：使用 `cell.PutValue(double)` 寫入數值型態
- **不可解析或空白**：使用 `cell.PutValue("")` 寫入空白字串

## 實作方式

### 1. 新增 Helper 方法
```csharp
private bool TryParseCredit(object value, out double credit)
{
    credit = 0;
    
    // null / 空白 / 只有空白字元 → 回傳 false
    if (value == null)
        return false;
    
    string strValue = value.ToString().Trim();
    if (string.IsNullOrEmpty(strValue))
        return false;
    
    // 嘗試解析為數字（含小數）
    if (double.TryParse(strValue, out double result))
    {
        credit = result;
        return true;
    }
    
    // 不可解析 → 回傳 false（保持空白，不要丟例外）
    return false;
}
```

### 2. 修改所有寫入點
原本寫法：
```csharp
wstSC.Cells[rowIdx, GetColIndex("學分數")].PutValue(data.Credit);
```

修改後：
```csharp
// 學分數改為數值型態寫入
if (TryParseCredit(data.Credit, out double creditValue))
{
    wstSC.Cells[rowIdx, GetColIndex("學分數")].PutValue(creditValue);
}
else
{
    wstSC.Cells[rowIdx, GetColIndex("學分數")].PutValue("");
}
```

## 測試

### 測試案例
- `null` → 空白
- `""` → 空白
- `"  "` → 空白
- `"2"` → 數值 2
- `"2.0"` → 數值 2.0
- `"0.5"` → 數值 0.5
- `"abc"` → 空白（不可解析）
