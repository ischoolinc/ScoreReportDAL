# 高中批次刪除課程功能調整（0116）

## 修改日期
2026-01-16

## 修改檔案
- `UIForm/frmDeleteCourseStudent.cs`

---

## 修改目的
在「批次刪除課程與修課」流程中，新增調代課對應資料（`dc_bind_key`）的檢查與刪除處理，確保刪除課程時一併清理相關的調代課對應資料。

---

## 新增功能

### 1. 成員變數（狀態快取）
在 `frmDeleteCourseStudent` 類別中新增：
- `_CourseBindCountDict`: Dictionary<string, int> - 儲存各課程的調代課對應筆數（key: course_id, value: count，預設 -1 表示未取得）
- `_HasCourseBindData`: bool - 標記是否存在任何調代課資料

### 2. _bgWorker_DoWork：查詢 dc_bind_key 筆數快取
- **位置**：在取得課程ID與名稱之後、取得修課紀錄之前（約 ReportProgress(50) 之後）
- **功能**：
  - 查詢 `dc_bind_key` 資料表，統計各課程的調代課對應筆數
  - 使用 `ref_course_id IN (課程清單)` 批次查詢
  - 將結果快取至 `_CourseBindCountDict` 和 `_HasCourseBindData`
  - 預設值為 -1（表示未取得資料）

### 3. _bgWorkerDel_DoWork：刪除 dc_bind_key + ApplicationLog 記錄
- **位置**：在既有刪除流程的最前面（在任何 DELETE 操作之前）
- **執行順序**：
  1. 取得預計刪除筆數（僅當 `_HasCourseBindData` 為 true 時）
  2. 刪除 `dc_bind_key` 資料（僅當 `_HasCourseBindData` 為 true 時）
  3. 記錄刪除筆數到 `ApplicationLog`（僅當 `delBindCount > 0` 時）

---

## SQL 說明

### 查詢調代課對應筆數
```sql
SELECT ref_course_id, COUNT(*) AS cnt
FROM dc_bind_key
WHERE ref_course_id IN (課程ID清單)
GROUP BY ref_course_id;
```

### 取得刪除筆數
```sql
SELECT COUNT(*)
FROM dc_bind_key
WHERE ref_course_id IN (課程ID清單);
```

### 刪除調代課對應資料
```sql
DELETE FROM dc_bind_key
WHERE ref_course_id IN (課程ID清單);
```

**注意**：所有 SQL 皆使用 `IN (課程ID清單)` 批次處理，避免逐筆查詢。

---

## 刪除流程順序

修改後的刪除順序：
1. **刪除 `dc_bind_key`**（新增）
2. 刪除 `sce_take`（若 `_SCAttendIDList.Count > 0`）
3. 刪除 `sc_attend`（若 `_SCAttendIDList.Count > 0`）
4. 刪除 `course`
5. 記錄 `ApplicationLog`（課程刪除 log 保留，新增調代課刪除 log）

---

## 注意事項

1. **不新增任何 UI**：本修改不處理 UI 確認（不 MessageBox、不確認視窗），使用者確認在其他地方已處理
2. **不改動既有流程**：僅在既有刪除流程前面插入 `dc_bind_key` 的刪除，不影響原有的刪除順序與意圖
3. **批次處理**：所有 SQL 操作皆以 `IN (course_id...)` 批次處理，提升效能
4. **錯誤處理**：所有資料庫操作皆有 try-catch 錯誤處理，避免影響主流程
5. **條件執行**：僅當 `_HasCourseBindData` 為 true 時才執行刪除操作，避免不必要的查詢

---

## 驗證測試建議

建議測試以下三種情境：

1. **無 dc_bind_key 的課程刪除**
   - `delBindCount = 0`
   - `dc_bind_key` 不刪除（或刪除 0 筆）
   - 原有刪除流程正常執行

2. **有 dc_bind_key 的課程刪除**
   - `delBindCount > 0`
   - `dc_bind_key` 先被刪除
   - `ApplicationLog` 有「刪除筆數」記錄

3. **混合多門課**（部分有、部分無調代課資料）
   - `_HasCourseBindData = true`
   - `delBindCount` 為總和
   - 刪除後不殘留對應資料
