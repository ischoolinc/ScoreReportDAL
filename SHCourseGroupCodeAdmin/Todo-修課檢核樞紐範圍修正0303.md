## 背景問題（目前程式現況）
目前程式碼使用：
- `int lastDataRow = wstSC.Cells.MaxDataRow;`
- `string sourceRange = $"'... '!$A$1:$U${endRow}";`（含 `$A$1` 絕對參照）

在部分 Aspose.Cells 版本下，`PivotTable.ChangeDataSource(...)` 對 `"$A$1:$U$20847"` 這類絕對參照字串 **可能不接受（靜默失敗）**，造成你觀察到 Pivot 來源未改變/刷新仍吃舊快取。

## 任務清單

### 1) 新增「以 A 欄判斷最後資料列」的安全方法
在 `frmCheckSCAttendCourseCode.cs` 內新增 private helper（放在同一 class 內即可）：

- 方法名稱建議：`GetLastDataRowByColumnA(Worksheet ws, int headerRowIndex = 0)`
- 行為：
  1. 先從 `ws.Cells.MaxDataRow` 取得可能的最後列（0-based）
  2. 往上掃描 A 欄（col=0）直到找到 **非空白** 的儲存格（`StringValue` 非空）
  3. 若最後結果 <= headerRowIndex，表示只有標題，回傳 headerRowIndex（或回傳 -1 並由呼叫端 return）

> 用 A 欄的原因：避免 `MaxDataRow` 受到「殘留格式/舊資料/空白列」影響。

### 2) 以相容格式動態設定 Pivot 資料來源（避免 $ 絕對參照）
把原本：

- `string sourceRange = $"'{wstSC.Name}'!$A$1:$U${endRow}";`

改成：

- `string sourceRange = $"'{wstSC.Name}'!A1:U{endRow}";`  （**不使用 $**）

並將 `endRow` 改用 **任務 1 的方法**算出來：

- `lastRow = GetLastDataRowByColumnA(wstSC, headerRowIndex: 0)`
- `endRow = lastRow + 1`（轉成 1-based）

### 3) 避免共用 PivotCache 造成互相覆蓋（兩段式更新）
將更新 pivot 的迴圈改成兩段式（先全部 ChangeDataSource，再全部 Refresh/Calculate）：

**原因**：多個 PivotTable 可能共用 PivotCache；某些版本下逐一 Change+Refresh 會出現 cache 狀態互相影響，導致你看到「來源沒變/結果沒更新」。

建議結構：

1. `string[] src = new[] { sourceRange };`
2. `foreach (PivotTable pt in wsStat.PivotTables) pt.ChangeDataSource(src);`
3. `foreach (PivotTable pt in wsStat.PivotTables) { pt.RefreshData(); pt.CalculateData(); DisableSubtotalsForField(...); }`

### 4) 保留既有功能：DisableSubtotalsForField
`DisableSubtotalsForField(pt, "部定校訂");` 不要移除，僅調整其呼叫位置（仍在 Calculate 後）。

### 5) 加上防呆與可讀性註解
- 若 `lastRow < 1`（只有標題或無資料），直接 `return;`
- 在組合 `sourceRange` 的位置加註解，說明：
  - 固定欄位 A~U
  - 來源字串採用 `SheetName!A1:U{n}` 格式以相容 `ChangeDataSource`
