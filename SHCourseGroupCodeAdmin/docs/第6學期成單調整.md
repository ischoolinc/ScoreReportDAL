# 第6學期成單調整：GradeData 處理分離與錯誤訊息修正

## 修改目的

1. 以 `chkExportJSON` 控制是否另存與 PDF 同名的獨立 `.json` 備份檔；不影響 PDF 產出與 `GradeData` Metadata 寫入。
2. 將 GradeData 建立、PDF Metadata 寫入、獨立 JSON 輸出拆成獨立步驟，使失敗時能正確標示實際失敗階段，避免一律顯示「第六學期成績單 Metadata 寫入失敗」。

## 修改檔案

- `Report/Student6thSemesterCorseCodeRank.cs`
- `Report/Student6thSemesterCorseCodeRank.Designer.cs`（先前新增 `chkExportJSON`）

## 錯誤訊息誤導的原因

原本 `WriteGradeDataToPdf` 將下列步驟綁在同一方法內：

1. `BuildGradeDataJson`
2. PDF Metadata（`SetMetaInfo` / `SaveNewInfo`）
3. 獨立 `.json` 檔寫入

外層 `TryWriteGradeDataToPdf` 與訊息框標題皆固定使用「第六學期成績單 Metadata 寫入失敗」。因此即使失敗發生在 GradeData 建立或 JSON 檔輸出，畫面仍顯示為 Metadata 失敗。

## 方法建立／重構

| 方法 | 職責 |
|------|------|
| `BuildGradeDataJson` | 既有商業邏輯，組出 GradeData JSON（業務規則未改） |
| `TryBuildGradeDataJson` | 包裝建立失敗為「GradeData 資料建立失敗：…」 |
| `WriteGradeDataMetadataToPdf` | 僅將已準備好的 JSON 寫入 PDF Metadata；失敗為「PDF Metadata 寫入失敗：…」 |
| `WriteGradeDataJsonFile` | 僅寫出同名 `.json`；失敗為「JSON 檔案輸出失敗：…」 |
| `WriteGradeDataToPdf` | 協調上述三步驟 |
| `TryWriteGradeDataToPdf` | 單一學生失敗時記錄訊息，不中斷其他學生 |

## GradeData 建立如何分離

```csharp
private string TryBuildGradeDataJson(string studentID)
{
    try
    {
        return BuildGradeDataJson(studentID);
    }
    catch (Exception ex)
    {
        throw new Exception("GradeData 資料建立失敗：" + ex.Message, ex);
    }
}
```

建立失敗時不會繼續寫 Metadata 或獨立 JSON。

## PDF Metadata 寫入如何分離

```csharp
private void WriteGradeDataMetadataToPdf(string pdfPath, string json)
{
    // BindPdf → SetMetaInfo("GradeData", json) → SaveNewInfo(pdfPath)
    // finally: fileInfo.Close()
}
```

欄位名稱仍為 `GradeData`，仍使用 `SetMetaInfo` / `SaveNewInfo`（不使用 `SaveNewInfoWithXmp`）。

## 獨立 JSON 輸出如何分離

```csharp
private void WriteGradeDataJsonFile(string pdfPath, string json)
{
    File.WriteAllText(
        Path.ChangeExtension(pdfPath, ".json"),
        json,
        new UTF8Encoding(false));
}
```

僅在 `_ExportJSON == true` 時由 `WriteGradeDataToPdf` 呼叫。

## chkExportJSON 僅影響獨立 JSON

協調流程：

```csharp
string json = TryBuildGradeDataJson(studentID);
WriteGradeDataMetadataToPdf(pdfPath, json);
if (_ExportJSON)
{
    WriteGradeDataJsonFile(pdfPath, json);
}
```

取消勾選時仍會建立 GradeData 並寫入 PDF Metadata，僅略過獨立 `.json`。

BackgroundWorker 執行前於 `btnPrint_Click` 擷取：

```csharp
_ExportJSON = chkExportJSON.Checked;
```

處理方法使用 `_ExportJSON`，不直接讀取控制項。

## 錯誤清單變數更名

`gradeMetaErrorList` → `gradeDataErrorList`

清單可包含 GradeData 建立、PDF Metadata、JSON 檔輸出錯誤。

## 訊息框標題更新

由「第六學期成績單 Metadata 寫入失敗」改為「第六學期成績資料處理失敗」。

外層訊息範例：

```text
第六學期成績資料處理失敗（學生系統編號 123，身分證號 A123456789）：GradeData 資料建立失敗：……
```

已使用 `string.Format(...)`，`{0}`／`{1}`／`{2}` 會替換為學生系統編號、身分證號、實際例外訊息。
