# 產生課程規劃調整 0909

## 修改檔案

- `UIForm\frmCreateGPlanItemSetup108.cs`

## 變更內容

將批次修改選單 `_ProcessList` 由僅含「略過」擴充為同時包含「略過」與「刪除」。

### 變更前

```csharp
List<string> _ProcessList = new List<string>() { 
     "略過"};
```

### 變更後

```csharp
List<string> _ProcessList = new List<string>()
{
    "略過",
    "刪除"
};
```

## 變更原因

讓使用者在「產生課程規劃細項」畫面中，可透過批次修改手動將選取列的「處理方式」設為「刪除」，而不僅限於「略過」。

## 行為說明

- 表單載入時依 `_ProcessList` 建立 `menuUpdateStatus` 選單項目，因此會同時顯示「略過」「刪除」。
- 既有 `menuUpdateStatus_ItemClicked` 會將選取列的「處理方式」設為選單文字，無需額外修改即可支援「刪除」。
- 既有 `dgDataCount()`、`btnSave_Click` 已支援「刪除」狀態的統計與寫回 `ProcessStatus`。
