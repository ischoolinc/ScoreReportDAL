- 型態：`Dictionary<string, List<string>>`

## Step 3 — 解析 Subject，遇到「分組名稱」就寫入 Dict
在 `foreach (XElement elm in ContentXML.Elements("Subject"))` 迴圈內，且在你產生 `key = SubjectName + "_" + Level` 之後加入：

### 解析與寫入規則
- 讀取分組名稱：`elm.Attribute("分組名稱")?.Value ?? ""`
- 若 `!string.IsNullOrWhiteSpace(groupName)`：
  - 若 Dict 沒有該 key，先建立 `new List<string>()`
  - 將 `key` 加入 List（需去重）

### 建議程式片段（可直接貼）
```csharp
string groupName = elm.Attribute("分組名稱")?.Value ?? "";
if (!string.IsNullOrWhiteSpace(groupName))
{
    if (!SubjectGroupDict.ContainsKey(groupName))
        SubjectGroupDict.Add(groupName, new List<string>());

    if (!SubjectGroupDict[groupName].Contains(key))
        SubjectGroupDict[groupName].Add(key);
}
```

✅ 驗收：
- 只有 `分組名稱` 有值的 Subject 才會被收集
- Dict 的 Key 不會出現空字串/空白
- 每個分組內的 `SubjectName_Level` 不會重複
