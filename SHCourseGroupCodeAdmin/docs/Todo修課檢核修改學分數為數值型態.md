## 目標
- 在 `frmCheckSCAttendCourseCode.cs` 產生 Excel 報表時，**學分數**欄位一律以「數值型態」寫入（避免被當成文字）。
- 修改完成後，將變更紀錄寫入：`修課檢核課程代碼調整0204.md`

## 範圍與不影響事項
- 僅調整「寫入 Excel 儲存格」時的型態處理（string → numeric）。
- 不改 SQL、不改資料來源內容、不改欄位名稱、不改其他欄位輸出格式。
- 需要確保：空白/NULL 仍維持空白（不要變成 0）。

## Step 1：新增通用轉型 Helper（建議集中管理）
在 `frmCheckSCAttendCourseCode.cs`（或適合的共用類別）新增方法：

- 方法名稱建議：`TryParseCredit(...)`
- 行為規格：
  - `null / 空白 / 只有空白字元` → 回傳 `false`
  - 可解析數字（含小數）→ 回傳 `true` 並輸出 `decimal`（或 `double`）
  - 不可解析（例如：`"-"`, `"N/A"`）→ 回傳 `false`（保持空白，不要丟例外）

範例規格（可依你專案 coding style 調整）：
- 輸入：`object value`
- 輸出：`bool` + `out decimal credit`

驗收：單元/手動測試以下輸入：
- `null`
- `""`
- `"  "`
- `"2"`
- `"2.0"`
- `"0.5"`
- `"abc"`

## Step 2：修改所有「學分數」寫入 Excel 的地方（必做）
對 Step 0 找到的每一個寫入點，套用相同策略：

### 2.1 若使用 Aspose.Cells（常見）
- 禁止：`cell.PutValue(string)` 寫入數字字串
- 改用：`cell.PutValue(double)` 或 `cell.PutValue(int)`（依實際資料）
- 空白/不可解析 → `cell.PutValue("")` 或不寫入

### 2.2 若使用 Interop / NPOI / 其他
- 以該套件的「數值儲存格」寫法寫入（不要用字串）

驗收：
- Excel 中該欄位數字「靠右」
- `ISNUMBER(儲存格)=TRUE`
- 若樣板包含樞紐分析/加總：能正常彙總（不為 0、不被當文字）

- 但注意：格式不應把空白變成 0

驗收：空白仍空白；數字顯示符合格式需求。
