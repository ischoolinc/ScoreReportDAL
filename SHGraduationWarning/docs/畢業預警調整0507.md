# 畢業預警調整0507

## 調整目標

調整畢業預警報表中 `非課規科目` 的判斷與顯示條件。

## 調整內容

1. 新增判斷 `學期科目成績屬性採計方式`。
2. 只有當 `學期科目成績屬性採計方式="以課程規劃表內容為準"` 時，才判斷並顯示 `非課規科目`。
3. 當 `學期科目成績屬性採計方式="以實際學期科目成績內容為準"` 時，不顯示 `非課規科目`。
4. `非課規科目` 判斷條件為：
   - `狀態="已取得"`
   - `非課程規劃表課程="非課程規劃表課程"`
5. `非課規科目` 即使 `學分數="0"` 也需要顯示。
6. 保留 `可重修`、`可補修`、`不採計` 原本判斷邏輯。
7. 未啟用 `課規不採計`。
8. 未啟用 `課規科目級別重複` 判斷。

## 預期狀態輸出

- 可重修
- 可補修
- 不採計
- 非課規科目
- 可重修、不採計
- 可補修、不採計
- 不採計、非課規科目

## 注意事項

- `非課規科目` 只接受 `狀態="已取得"`。
- `狀態="已修"` 不顯示 `非課規科目`。
- `學分數="0"` 的非課規科目仍需要顯示。
