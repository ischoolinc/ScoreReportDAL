
# 目標：修改不採計判斷

- `frmMain.cs`

## 修改完成後記錄

---

## 一、修改目標說明

本次目標是調整「畢業預警」報表產生時的科目狀態輸出邏輯。

目前要改成：

1. `課規科目級別重複` 相關的 `課規不採計` 判斷與功能全部註解或停用。
2. `成績科目級別重複` 仍保留判斷。
3. 最後輸出到報表的 `狀態` 文字，由 `成績不採計` 改回 `不採計`。

---

## 二、保留原本功能

請保留原本以下邏輯，不要更動：

```csharp
狀態 == "可重修"
````

輸出：

```text
可重修
```

```csharp
狀態 == "尚未補修"
```

輸出到報表時仍顯示：

```text
可補修
```

---

## 三、停用課規不採計

請搜尋 `frmMain.cs` 內與下列文字相關的程式碼：

```text
課規科目級別重複
課規不採計
isPlanNotIncluded
```

請將這些判斷與功能註解或停用。

例如原本可能有：

```csharp
bool isPlanNotIncluded =
    xmlRuleS.GetAttribute("課規科目級別重複") == "不重複採計";
```

請改成註解：

```csharp
// 2026-05-06 調整：課規不採計暫停使用
// bool isPlanNotIncluded =
//     xmlRuleS.GetAttribute("課規科目級別重複") == "不重複採計";
```

如果原本有：

```csharp
if (isPlanNotIncluded)
    statusList.Add("課規不採計");
```

請改成註解：

```csharp
// 2026-05-06 調整：課規不採計暫停輸出
// if (isPlanNotIncluded)
//     statusList.Add("課規不採計");
```

## 四、調整 continue 條件

請找到類似以下條件：

```csharp
if (!isCanMakeup && !isCanRetake && !isScoreNotIncluded && !isPlanNotIncluded)
    continue;
```

請改成不包含 `isPlanNotIncluded`：

```csharp
if (!isCanMakeup && !isCanRetake && !isScoreNotIncluded)
    continue;
```

目的：

* 只有 `課規科目級別重複 == 不重複採計` 時，不再輸出到報表狀態。
* 只有可重修、可補修、成績不採計才會進入報表狀態處理。

---

## 五、成績科目級別重複輸出改回不採計

請保留 `成績科目級別重複` 判斷：

```csharp
bool isScoreNotIncluded =
    xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計";
```

但輸出文字要改回：

```text
不採計
```

如果目前程式是：

```csharp
if (isScoreNotIncluded)
    statusList.Add("成績不採計");
```

請改成：

```csharp
if (isScoreNotIncluded)
    statusList.Add("不採計");
```

## 六、狀態輸出順序

請維持固定輸出順序：

```text
可重修、可補修、不採計
```

建議程式如下：

```csharp
List<string> statusList = new List<string>();

if (isCanRetake)
    statusList.Add("可重修");

if (isCanMakeup)
    statusList.Add("可補修");

if (isScoreNotIncluded)
    statusList.Add("不採計");

subjectElement.SetAttribute("狀態", string.Join("、", statusList.ToArray()));
```

## 七、AddSubjectStatusIfNotExists 調整

請搜尋方法：

```csharp
AddSubjectStatusIfNotExists
```

如果之前有加入：

```csharp
if (s == "不採計")
    s = "成績不採計";
```

請移除或註解。

本次需求是最後輸出顯示：

```text
不採計
```

因此不要再把 `不採計` 轉成 `成績不採計`。

如果仍需要相容舊資料，可以只保留：

```csharp
if (s == "尚未補修")
    s = "可補修";
```

如果目前可能已經有舊文字 `成績不採計` 進來，請改成轉回：

```csharp
if (s == "成績不採計")
    s = "不採計";
```

建議完整概念如下：

```csharp
if (s == "尚未補修")
    s = "可補修";

if (s == "成績不採計")
    s = "不採計";
```

## 九、測試案例

請至少檢查以下輸出。

### 1. 只有可重修

條件：

```text
狀態 = 可重修
成績科目級別重複 != 不重複採計
課規科目級別重複 = 任意值
```

預期：

```text
可重修
```

---

### 2. 只有可補修

條件：

```text
狀態 = 尚未補修
成績科目級別重複 != 不重複採計
課規科目級別重複 = 任意值
```

預期：

```text
可補修
```

---

### 3. 只有成績不採計

條件：

```text
狀態不是 可重修 / 尚未補修
成績科目級別重複 = 不重複採計
課規科目級別重複 = 任意值
```

預期：

```text
不採計
```

---

### 4. 可重修 + 成績不採計

條件：

```text
狀態 = 可重修
成績科目級別重複 = 不重複採計
```

預期：

```text
可重修、不採計
```

---

### 5. 可補修 + 成績不採計

條件：

```text
狀態 = 尚未補修
成績科目級別重複 = 不重複採計
```

預期：

```text
可補修、不採計
```

---

### 6. 只有課規不採計

條件：

```text
狀態不是 可重修 / 尚未補修
成績科目級別重複 != 不重複採計
課規科目級別重複 = 不重複採計
```

預期：

```text
不輸出到科目狀態
```

說明：

```text
課規不採計已暫停使用，所以不能輸出 課規不採計。
```

---

### 7. 成績不採計 + 課規不採計

條件：

```text
成績科目級別重複 = 不重複採計
課規科目級別重複 = 不重複採計
```

預期：

```text
不採計
```

說明：

```text
只看成績科目級別重複，不看課規科目級別重複。
```

## 調整目標

修改畢業預警報表科目狀態的不採計判斷。

## 調整內容

1. 停用 `課規科目級別重複` 相關的 `課規不採計` 判斷與輸出。

- `可補修`

- `可重修、不採計`
- `可補修、不採計`
- `可重修、可補修、不採計`

## 注意事項

- `課規不採計` 暫停使用。
- `課規科目級別重複 == 不重複採計` 不再輸出到報表狀態。
