
## 目標

調整 `frmMain.cs` 中「可補修、可重修、非課規科目、不採計」等科目輸出欄位數量。

目前科目最多約 50 筆，部分核心科目打勾欄位甚至只有 30 筆。

本次目標：

```text
將相關科目輸出欄位上限統一調整為 130 筆。
````

修改完成後，請完整記錄在：

```text
畢業預警調整0603.md
```

# 三、目前限制位置

請在 `frmMain.cs` 搜尋：

```csharp
int maxSubj = 50;
```

目前大約會出現在建立報表 `DataTable` 欄位的位置。

原本：

```csharp
int maxSubj = 50;
```

請改成：

```csharp
int maxSubj = 130;
```

# 五、也要檢查寫死 30 的地方

請在 `frmMain.cs` 搜尋：

```csharp
j <= 30
```

或：

```csharp
for (int j = 1; j <= 30; j++)
```

目前可能有這段：

```csharp
for (int i = 1; i <= 5; i++)
{
    for (int j = 1; j <= 30; j++)
    {
        StudDT.Columns.Add("科目" + j + "_取得學分數統計_核心科目表序號" + i + "_規則_可補修重修_打勾");
    }
}
```

這裡目前只建立到 30 筆，請改成使用 `maxSubj`：

```csharp
for (int i = 1; i <= 5; i++)
{
    for (int j = 1; j <= maxSubj; j++)
    {
        StudDT.Columns.Add("科目" + j + "_取得學分數統計_核心科目表序號" + i + "_規則_可補修重修_打勾");
    }
}
```

注意：

```text
不要只把 30 改成 130。
建議改成 maxSubj，避免未來上限不一致。
```

if (StudDT.Columns.Contains(sK1))

```text

```

# 九、Word 樣板注意事項

程式建立欄位到 130 筆後，Word 樣板也需要有對應合併欄位才會顯示。

如果 Word 樣板只放到：

```text
科目50_狀態
科目50_科目名稱
```

那程式雖然產生到 130，報表仍只會顯示到樣板有放的欄位。

請確認 Word 樣板是否需要新增：

```text
科目51_狀態 ~ 科目130_狀態
科目51_修課學年度 ~ 科目130_修課學年度
科目51_修課學期 ~ 科目130_修課學期
科目51_科目名稱 ~ 科目130_科目名稱
科目51_科目級別 ~ 科目130_科目級別
科目51_學分數 ~ 科目130_學分數
```
