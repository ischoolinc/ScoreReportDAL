# 畢業預警調整 0505

## 修改檔案

- frmMain.cs

## 修改目標

- 調整畢業預警報表科目狀態「不採計」判斷，拆成兩種：
  - 成績不採計
  - 課規不採計
- 保留原本可補修判斷邏輯：XML 狀態仍使用「尚未補修」。
- 報表輸出時，將「尚未補修」顯示為「可補修」。
- 同科目同級別若同時符合可補修/可重修與不採計，狀態合併顯示，並固定輸出順序：
  - 可重修、可補修、成績不採計、課規不採計

## 修改重點

- 新增判斷：
  - 成績科目級別重複 == 不重複採計 → 成績不採計
  - 課規科目級別重複 == 不重複採計 → 課規不採計
- 報表用 XmlElement 採 CloneNode(true)，避免直接修改 GrandCheckReport 原始 XML。
- 同科目名稱 + 科目級別重複時，只合併狀態，不覆蓋原本修課學年度、修課學期、學分數等資料。
- 新增 AddSubjectStatusIfNotExists(...) 輔助方法，避免狀態重複。
  - 相容舊文字：不採計 → 成績不採計

## 測試結果

- 狀態=尚未補修 → 科目N_狀態=可補修
- 狀態=可重修 → 科目N_狀態=可重修
- 成績科目級別重複=不重複採計 → 科目N_狀態=成績不採計
- 課規科目級別重複=不重複採計 → 科目N_狀態=課規不採計
- 狀態=尚未補修 且 成績科目級別重複=不重複採計 → 科目N_狀態=可補修、成績不採計
- 狀態=可重修 且 成績科目級別重複=不重複採計 → 科目N_狀態=可重修、成績不採計
- 狀態=尚未補修 且 課規科目級別重複=不重複採計 → 科目N_狀態=可補修、課規不採計
- 狀態=可重修 且 課規科目級別重複=不重複採計 → 科目N_狀態=可重修、課規不採計
- 成績科目級別重複=不重複採計 且 課規科目級別重複=不重複採計 → 科目N_狀態=成績不採計、課規不採計
