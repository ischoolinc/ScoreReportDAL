# 二、目前問題

目前程式端 `frmMain.cs` 已經支援科目欄位到 130 筆。

但是 `.docx` 樣板中多個表格目前只放到第 50 筆，例如：

```text
科目1_...
...
科目50_...
```

因此如果學生資料超過 50 筆，程式雖然有產生：

```text
科目51_...
...
科目130_...
```

但 Word 樣板沒有對應合併欄位時，報表不會顯示第 51～130 筆。

# 四、建議修改方式

## 4.1 不建議人工逐欄修改

不要直接在 Word 畫面中只複製：

```text
«S»
«V»
```

原因：

```text
«S»、«V» 只是 Word 顯示出來的合併欄位結果。
真正要修改的是背後的 MERGEFIELD 欄位代碼。
```

---

## 4.2 建議用自動化工具處理

建議用 Python 或 C# 自動處理 `.docx`。

處理方式：

```text
1. 開啟 .docx。
2. 找到目標表格。
3. 找到目前第 50 筆資料列。
4. 複製第 50 筆資料列格式。
5. 依序新增第 51～130 筆。
6. 每一列的序號改成目前 N。
7. 每一列內所有 MERGEFIELD 欄位代碼：
   將 科目50_ 替換為 科目N_。
8. 保留原本表格格式、框線、字型、對齊方式。
9. 儲存為新版 .docx。
```

# 五、合併欄位處理注意

Word 合併欄位通常不是普通文字，可能長這樣：

```text
{ MERGEFIELD 科目50_狀態 \* MERGEFORMAT }
```

新增第 51 筆時，必須變成：

```text
{ MERGEFIELD 科目51_狀態 \* MERGEFORMAT }
```

新增第 130 筆時，必須變成：

```text
{ MERGEFIELD 科目130_狀態 \* MERGEFORMAT }
```

不能只是把畫面文字改成：

```text
«科目130_狀態»
```
