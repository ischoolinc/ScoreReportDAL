# 畢業預警調整0506

## 新增狀態說明

### 修改檔案

- frmMain.cs

### 修改位置

- LoadTabDesc()
- SelectedTabName == GWTabName 的畢業預警說明區塊

### 調整內容

在原本 `Properties.Resources.畢業預警說明` 後方追加狀態說明文字。

### 新增文字

狀態說明:
「可重修」：可重新修課，取得學分。
「可補修」：可選擇補修，取得學分。
「非課規科目」：不屬於課程規畫表內，不列入畢業學分。
「不採計」：同科目級別已修習，不重複採計學分。

### 注意事項

- 未修改 Resources.resx。
- 未修改畢業預警資料查詢邏輯。
- 未修改產生報表邏輯。
- 未修改可重修、可補修、不採計判斷邏輯。

## 調整目標

修改畢業預警報表科目狀態的不採計判斷。

## 調整內容

1. 停用 `課規科目級別重複` 相關的 `課規不採計` 判斷與輸出。
2. 保留 `成績科目級別重複 == 不重複採計` 的判斷。
3. 將原本輸出的 `成績不採計` 改回 `不採計`。
4. 保留 `可重修`、`可補修` 原本輸出邏輯。
5. `AddSubjectStatusIfNotExists` 不再將 `不採計` 轉成 `成績不採計`。
6. 如遇到既有 `成績不採計` 文字，統一轉回 `不採計`。

## 預期輸出

- `可重修`
- `可補修`
- `不採計`
- `可重修、不採計`
- `可補修、不採計`
- `可重修、可補修、不採計`

## 注意事項

- `課規不採計` 暫停使用。
- `課規科目級別重複 == 不重複採計` 不再輸出到報表狀態。

## 新增非課規科目

### 修改檔案

- frmMain.cs

### 調整目標

在畢業預警報表的科目狀態輸出中新增 `非課規科目`。

### 判斷條件

符合以下條件時輸出 `非課規科目`：

```csharp
status == "已取得" &&
xmlRuleS.GetAttribute("非課程規劃表課程") == "非課程規劃表課程"
```

### 調整內容

1. 新增 `isNonGraduationPlanSubject` 判斷。
2. 調整 `學分數 == "0"` 的跳過條件，避免非課規科目被略過。
3. 在狀態輸出中新增 `非課規科目`。
4. 保留 `可重修`、`可補修`、`不採計` 原本判斷邏輯。
5. 未啟用 `課規不採計`。
6. 未啟用 `課規科目級別重複` 判斷。

### 預期狀態輸出

- 可重修
- 可補修
- 不採計
- 非課規科目
- 可重修、不採計
- 可補修、不採計
- 不採計、非課規科目

### 注意事項

- `非課規科目` 只接受 `狀態="已取得"`。
- `狀態="已修"` 不輸出 `非課規科目`。
- `學分數="0"` 的非課規科目仍需保留輸出。
