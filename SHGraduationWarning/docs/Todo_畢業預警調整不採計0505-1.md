
# 目標：新增與調整不採計判斷

## 修改檔案

- `frmMain.cs`

## 修改完成後記錄

- `畢業預警調整0505.md`

---

## 一、修改目標說明

本次目標是調整「畢業預警」報表中，科目狀態輸出的不採計判斷。

原本只有一種：

- `不採計`

本次要調整成兩種：

- `成績不採計`
- `課規不採計`

其中：

```csharp
xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計"
````

輸出：

```text
成績不採計
```

新增：

```csharp
xmlRuleS.GetAttribute("課規科目級別重複") == "不重複採計"
```

輸出：

```text
課規不採計
```

---

## 二、保留原本邏輯

請保持原本「可重修」、「可補修」邏輯不變。

原本：

```csharp
狀態 == "可重修"
```

輸出：

```text
可重修
```

原本：

```csharp
狀態 == "尚未補修"
```

輸出到報表時，要顯示：

```text
可補修
```

---

## 三、要調整的判斷邏輯

請找到原本處理科目狀態的區塊，通常會有類似：

```csharp
bool isCanMakeup = status == "尚未補修";
bool isCanRetake = status == "可重修";
bool isNotIncluded = xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計";
```

請改成：

```csharp
bool isCanMakeup = status == "尚未補修";
bool isCanRetake = status == "可重修";

bool isScoreNotIncluded =
    xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計";

bool isPlanNotIncluded =
    xmlRuleS.GetAttribute("課規科目級別重複") == "不重複採計";
```

原本：

```csharp
if (!isCanMakeup && !isCanRetake && !isNotIncluded)
    continue;
```

請改成：

```csharp
if (!isCanMakeup && !isCanRetake && !isScoreNotIncluded && !isPlanNotIncluded)
    continue;
```

---

## 四、狀態文字輸出規則

請將原本單一 `不採計` 改成以下兩種：

```csharp
if (isScoreNotIncluded)
    statusList.Add("成績不採計");

if (isPlanNotIncluded)
    statusList.Add("課規不採計");
```

建議輸出順序固定為：

```text
可重修、可補修、成績不採計、課規不採計
```

程式寫法建議：

```csharp
List<string> statusList = new List<string>();

if (isCanRetake)
    statusList.Add("可重修");

if (isCanMakeup)
    statusList.Add("可補修");

if (isScoreNotIncluded)
    statusList.Add("成績不採計");

if (isPlanNotIncluded)
    statusList.Add("課規不採計");

subjectElement.SetAttribute("狀態", string.Join("、", statusList.ToArray()));
```

## 五、合併狀態時要避免重複

如果同一個 `科目名稱 + 科目級別` 已經存在，請維持原本合併狀態的方式，不要覆蓋原本資料。

例如同一科目不同資料來源可能出現：

```text
可重修、成績不採計
```

另一筆出現：

```text
可補修、課規不採計
```

合併後應為：

```text
可重修、成績不採計、可補修、課規不採計
```

或依固定順序整理為：

```text
可重修、可補修、成績不採計、課規不採計
```

請使用既有的 `AddSubjectStatusIfNotExists(...)` 或等效邏輯處理，避免重複加入相同文字。

---

## 六、AddSubjectStatusIfNotExists 需相容舊文字

請找到方法：

```csharp
AddSubjectStatusIfNotExists(...)
```

如果方法中已經有：

```csharp
if (s == "尚未補修")
    s = "可補修";
```

請新增舊文字轉換：

```csharp
if (s == "不採計")
    s = "成績不採計";
```

完整概念如下：

```csharp
if (s == "尚未補修")
    s = "可補修";

if (s == "不採計")
    s = "成績不採計";
```

目的：

* 舊的 `不採計` 不再輸出
* 舊資料或舊流程若仍傳入 `不採計`，統一轉成 `成績不採計`

---

## 七、請移除或不要新增 Debug Console.WriteLine

如果程式中有類似：

```csharp
if (xmlRuleS.GetAttribute("課規科目級別重複") == "不重複採計")
{
    Console.WriteLine(...);
}
```

請移除或不要新增。

本次功能應正式輸出到報表狀態，不應只寫 Console。

## 八、測試案例

請至少檢查以下狀態輸出。

### 1. 只有可重修

條件：

```text
狀態 = 可重修
成績科目級別重複 != 不重複採計
課規科目級別重複 != 不重複採計
```

預期：

```text
可重修
```

---

### 2. 只有可補修

條件：

```text
狀態 = 尚未補修
成績科目級別重複 != 不重複採計
課規科目級別重複 != 不重複採計
```

預期：

```text
可補修
```

---

### 3. 只有成績不採計

條件：

```text
狀態不是 可重修 / 尚未補修
成績科目級別重複 = 不重複採計
課規科目級別重複 != 不重複採計
```

預期：

```text
成績不採計
```

---

### 4. 只有課規不採計

條件：

```text
狀態不是 可重修 / 尚未補修
成績科目級別重複 != 不重複採計
課規科目級別重複 = 不重複採計
```

預期：

```text
課規不採計
```

---

### 5. 可重修 + 成績不採計

條件：

```text
狀態 = 可重修
成績科目級別重複 = 不重複採計
```

預期：

```text
可重修、成績不採計
```

---

### 6. 可補修 + 課規不採計

條件：

```text
狀態 = 尚未補修
課規科目級別重複 = 不重複採計
```

預期：

```text
可補修、課規不採計
```

---

### 7. 成績不採計 + 課規不採計

條件：

```text
成績科目級別重複 = 不重複採計
課規科目級別重複 = 不重複採計
```

預期：

```text
成績不採計、課規不採計
```

---

### 8. 可重修 + 可補修 + 成績不採計 + 課規不採計

如果同一個 `科目名稱 + 科目級別` 因多筆資料合併後同時存在：

```text
可重修
可補修
成績不採計
課規不採計
```

預期合併後：

```text
可重修、可補修、成績不採計、課規不採計
```
