# 目標：新增狀態說明

## 修改檔案

- `frmMain.cs`

## 修改完成後記錄

- `畢業預警調整0506.md`

---

## 一、修改目標說明

本次目標是在 `frmMain.cs` 內，直接於原本載入「畢業預警說明」的位置，額外追加「狀態說明」文字。

不要修改 `Resources.resx`。  
不要修改 `Properties.Resources.畢業預警說明` 原始資源內容。

---

## 二、修改位置

請在 `frmMain.cs` 搜尋方法：

```csharp
private string LoadTabDesc()
````

或搜尋：

```csharp
Properties.Resources.畢業預警說明
```

應會找到類似程式：

```csharp
// 載入說明資訊
private string LoadTabDesc()
{
    string msg = "";

    // 畢業預警
    if (SelectedTabName == GWTabName)
    {
        msg = Properties.Resources.畢業預警說明;
    }

    ...
}
```

---

## 三、修改方式

請只調整「畢業預警」這段。

原本：

```csharp
if (SelectedTabName == GWTabName)
{
    msg = Properties.Resources.畢業預警說明;
}
```

請改成：

```csharp
if (SelectedTabName == GWTabName)
{
    msg = Properties.Resources.畢業預警說明;

    msg += "\r\n\r\n";
    msg += "狀態說明:\r\n";
    msg += "「可重修」：可重新修課，取得學分。\r\n";
    msg += "「可補修」：可選擇補修，取得學分。\r\n";
    msg += "「非課規科目」：不屬於課程規畫表內，不列入畢業學分。\r\n";
    msg += "「不採計」：同科目級別已修習，不重複採計學分。";
}
```

---

## 四、顯示結果

說明視窗原本內容下方要空一行，新增：

```text
狀態說明:
「可重修」：可重新修課，取得學分。
「可補修」：可選擇補修，取得學分。
「非課規科目」：不屬於課程規畫表內，不列入畢業學分。
「不採計」：同科目級別已修習，不重複採計學分。
```

---

## 五、注意事項

1. 不要修改 `Resources.resx`。
2. 不要修改 `Properties.Resources.畢業預警說明`。
3. 不要修改其他頁籤的說明文字。
4. 不要修改畢業預警查詢、產生清單、產生報表邏輯。
5. 不要修改可重修、可補修、不採計的判斷邏輯。
6. 只在 `SelectedTabName == GWTabName` 的說明內容後面追加文字。
7. 請使用 `\r\n` 換行，保持 Windows 說明視窗顯示正常。


6. 其他頁籤的說明內容不受影響。
