# 目標：調整非課規科目判斷與顯示

## 修改檔案

- `frmMain.cs`

## 修改完成後記錄

- `畢業預警調整0507.md`

---

## 一、修改目標說明

本次目標是調整畢業預警報表中「非課規科目」的判斷條件。

新增規則：

只有當 GrandCheckReport 根節點屬性：

```xml
學期科目成績屬性採計方式="以課程規劃表內容為準"
````

才需要判斷並顯示：

```text
非課規科目
```

如果是：

```xml
學期科目成績屬性採計方式="以實際學期科目成績內容為準"
```

則不需要判斷，也不顯示：

```text
非課規科目
```

---

## 二、非課規科目判斷條件

請在處理科目狀態的位置新增或調整判斷。

非課規科目必須同時符合以下條件：

```csharp
rs.GraGrandCheckXml.GetAttribute("學期科目成績屬性採計方式") == "以課程規劃表內容為準"
```

且：

```csharp
status == "已取得"
```

且：

```csharp
xmlRuleS.GetAttribute("非課程規劃表課程") == "非課程規劃表課程"
```

請注意：

* 只接受 `狀態="已取得"`。
* 不接受 `狀態="已修"`。
* 不要判斷 `課規科目級別重複`。
* 不要新增或恢復 `課規不採計`。

---

## 三、建議程式寫法

請在處理每一個 `xmlRuleS` 的區塊中，先取得目前 GrandCheckReport 的採計方式。

建議寫法如下：

```csharp
bool isUseCoursePlanSubjectAttribute =
    rs.GraGrandCheckXml.GetAttribute("學期科目成績屬性採計方式") == "以課程規劃表內容為準";
```

接著保留原本狀態判斷：

```csharp
string status = xmlRuleS.GetAttribute("狀態");

bool isCanMakeup = status == "尚未補修";
bool isCanRetake = status == "可重修";

bool isScoreNotIncluded =
    xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計";
```

新增非課規科目判斷：

```csharp
bool isNonGraduationPlanSubject =
    isUseCoursePlanSubjectAttribute &&
    status == "已取得" &&
    xmlRuleS.GetAttribute("非課程規劃表課程") == "非課程規劃表課程";
```

---

## 四、重要：非課規科目學分數 0 也需要出現

原本可能有這段：

```csharp
if (xmlRuleS.GetAttribute("學分數") == "0")
    continue;
```

這會造成符合非課規科目條件，但 `學分數="0"` 的資料被跳過。

本次需求是：

```text
非課規科目 即使 學分數="0" 也需要出現
```

所以請改成：

```csharp
if (xmlRuleS.GetAttribute("學分數") == "0" && !isNonGraduationPlanSubject)
    continue;
```

意思是：

* 一般科目仍維持原本邏輯，`學分數="0"` 就跳過。
* 但如果符合 `非課規科目`，即使 `學分數="0"` 也要保留並輸出狀態。

---

## 五、調整狀態進入條件

原本可能是：

```csharp
if (!isCanMakeup && !isCanRetake && !isScoreNotIncluded)
    continue;
```

請改成：

```csharp
if (!isCanMakeup && !isCanRetake && !isScoreNotIncluded && !isNonGraduationPlanSubject)
    continue;
```

目的：

讓符合 `非課規科目` 的科目可以進入狀態輸出流程。

---

## 六、狀態輸出

請保留原本輸出順序：

```text
可重修、可補修、不採計
```

並在後方新增：

```text
非課規科目
```

建議程式：

```csharp
List<string> statusList = new List<string>();

if (isCanRetake)
    statusList.Add("可重修");

if (isCanMakeup)
    statusList.Add("可補修");

if (isScoreNotIncluded)
    statusList.Add("不採計");

if (isNonGraduationPlanSubject)
    statusList.Add("非課規科目");

subjectElement.SetAttribute("狀態", string.Join("、", statusList.ToArray()));
```

預期輸出順序：

```text
可重修、可補修、不採計、非課規科目
```

---

## 七、不要影響既有判斷邏輯

請不要修改以下既有判斷：

### 可重修

```csharp
bool isCanRetake = status == "可重修";
```

### 可補修

```csharp
bool isCanMakeup = status == "尚未補修";
```

### 不採計

```csharp
bool isScoreNotIncluded =
    xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計";
```

### 不採計輸出文字

請維持：

```csharp
statusList.Add("不採計");
```

不要改成：

```csharp
statusList.Add("成績不採計");
```

## 八、不要啟用課規不採計

請確認不要新增或恢復以下邏輯：

```csharp
xmlRuleS.GetAttribute("課規科目級別重複") == "不重複採計"
```

也不要輸出：

```text
課規不採計
```

本次需求只新增：

```text
非課規科目
```

## 九、測試案例

### 1. 採計方式為課程規劃表內容，且符合非課規科目

條件：

```xml
學期科目成績屬性採計方式="以課程規劃表內容為準"
```

且科目：

```xml
狀態="已取得"
非課程規劃表課程="非課程規劃表課程"
學分數="0"
```

預期：

```text
非課規科目
```

---

### 2. 採計方式為實際學期科目成績內容，即使有非課程規劃表課程也不顯示

條件：

```xml
學期科目成績屬性採計方式="以實際學期科目成績內容為準"
```

且科目：

```xml
狀態="已取得"
非課程規劃表課程="非課程規劃表課程"
學分數="0"
```

預期：

```text
不顯示 非課規科目
```

---

### 3. 非課規科目只接受已取得

條件：

```xml
學期科目成績屬性採計方式="以課程規劃表內容為準"
```

且科目：

```xml
狀態="已修"
非課程規劃表課程="非課程規劃表課程"
```

預期：

```text
不顯示 非課規科目
```

---

### 4. 可補修不受影響

條件：

```xml
狀態="尚未補修"
學分數="2"
```

預期：

```text
可補修
```

---

### 5. 可重修不受影響

條件：

```xml
狀態="可重修"
學分數="2"
```

預期：

```text
可重修
```

---

### 6. 不採計不受影響

條件：

```xml
成績科目級別重複="不重複採計"
學分數="2"
```

預期：

```text
不採計
```

---

### 7. 不採計 + 非課規科目

條件：

```xml
學期科目成績屬性採計方式="以課程規劃表內容為準"
```

且科目：

```xml
狀態="已取得"
成績科目級別重複="不重複採計"
非課程規劃表課程="非課程規劃表課程"
學分數="0"
```

預期：

```text
不採計、非課規科目
```

# 畢業預警調整0507

調整畢業預警報表中 `非課規科目` 的判斷與顯示條件。

1. 新增判斷 `學期科目成績屬性採計方式`。

- 可重修
- 可補修
- 不採計
- 非課規科目

- 可補修、不採計

## 注意事項

- `非課規科目` 只接受 `狀態="已取得"`。
