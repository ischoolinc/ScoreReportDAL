# 目標：新增非課規科目狀態

## 修改檔案

- `frmMain.cs`

## 修改完成後記錄

- `畢業預警調整0506.md`

---

## 一、修改目標說明

本次目標是在畢業預警「產生報表」的科目狀態輸出中，新增一種狀態：

```text
非課規科目
````

新增判斷條件：

```csharp
狀態 == "已取得"
&&
xmlRuleS.GetAttribute("非課程規劃表課程") == "非課程規劃表課程"
```

注意：

* 只接受 `狀態="已取得"`。
* 不接受 `狀態="已修"`。
* 不要影響原本 `可重修`、`可補修`、`不採計` 判斷邏輯。
* 不要恢復或新增 `課規不採計`。
* `課規科目級別重複` 相關判斷仍維持停用。

---

## 二、修改位置

請在 `frmMain.cs` 搜尋處理畢業預警報表科目狀態的區塊。

可搜尋以下關鍵字：

```csharp
bool isCanMakeup
```

或：

```csharp
bool isScoreNotIncluded
```

或：

```csharp
statusList.Add("不採計");
```

應該會找到類似邏輯：

```csharp
string status = xmlRuleS.GetAttribute("狀態");

bool isCanMakeup = status == "尚未補修";
bool isCanRetake = status == "可重修";

bool isScoreNotIncluded =
    xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計";

if (xmlRuleS.GetAttribute("學分數") == "0")
    continue;

if (!isCanMakeup && !isCanRetake && !isScoreNotIncluded)
    continue;
```

---

## 三、新增非課規科目判斷

請在 `isScoreNotIncluded` 後方新增：

```csharp
bool isNonGraduationPlanSubject =
    status == "已取得" &&
    xmlRuleS.GetAttribute("非課程規劃表課程") == "非課程規劃表課程";
```

請注意：

不要寫成：

```csharp
status == "已修"
```

也不要寫成：

```csharp
(status == "已取得" || status == "已修")
```

本次只允許：

```csharp
status == "已取得"
```

---

## 四、調整學分數為 0 的 continue 條件

原本可能有：

```csharp
if (xmlRuleS.GetAttribute("學分數") == "0")
    continue;
```

請改成：

```csharp
if (xmlRuleS.GetAttribute("學分數") == "0" && !isNonGraduationPlanSubject)
    continue;
```

原因：

範例 XML 中 `非課程規劃表課程` 可能是：

```xml
<科目 科目名稱="英語文" 科目級別="2" 學分數="0" 取得學分數="0" 修課學年度="112" 修課年級="1" 修課學期="2" 狀態="已取得" 非課程規劃表課程="非課程規劃表課程" />
```

如果維持原本 `學分數 == "0"` 就直接 `continue`，會導致 `非課規科目` 永遠不會輸出。

---

## 五、調整狀態判斷 continue 條件

原本可能有：

```csharp
if (!isCanMakeup && !isCanRetake && !isScoreNotIncluded)
    continue;
```

請改成：

```csharp
if (!isCanMakeup && !isCanRetake && !isScoreNotIncluded && !isNonGraduationPlanSubject)
    continue;
```

目的：

讓符合 `非課規科目` 條件的科目可以進入後續狀態輸出。

---

## 六、新增狀態輸出

找到狀態輸出區塊，應該類似：

```csharp
List<string> statusList = new List<string>();

if (isCanRetake)
    statusList.Add("可重修");

if (isCanMakeup)
    statusList.Add("可補修");

if (isScoreNotIncluded)
    statusList.Add("不採計");

subjectElement.SetAttribute("狀態", string.Join("、", statusList.ToArray()));
```

請新增：

```csharp
if (isNonGraduationPlanSubject)
    statusList.Add("非課規科目");
```

建議完整順序如下：

```csharp
List<string> statusList = new List<string>();

if (isCanRetake)
    statusList.Add("可重修");

if (isCanMakeup)
    statusList.Add("可補修");

if (isScoreNotIncluded)
    statusList.Add("不採計");

if (isNonGraduationPlanSubject)
    statusList.Add("非課規科目");

subjectElement.SetAttribute("狀態", string.Join("、", statusList.ToArray()));
```

預期輸出順序：

```text
可重修、可補修、不採計、非課規科目
```

---

## 七、不要修改的邏輯

請不要修改以下既有邏輯：

1. 不要修改 `可重修` 判斷：

```csharp
bool isCanRetake = status == "可重修";
```

2. 不要修改 `可補修` 判斷：

```csharp
bool isCanMakeup = status == "尚未補修";
```

3. 不要修改 `不採計` 判斷：

```csharp
bool isScoreNotIncluded =
    xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計";
```

4. 不要將 `不採計` 改成 `成績不採計`。

5. 不要新增或恢復：

```csharp
課規不採計
```

6. 不要啟用：

```csharp
課規科目級別重複
```

7. 不要修改 `GrandCheckReport` 產生邏輯。

8. 不要修改 Word 合併欄位名稱。

9. 不要修改畫面查詢、載入學生資料、載入班級資料流程。

10. 不要新增 `Console.WriteLine` debug 訊息。

## 八、AddSubjectStatusIfNotExists 合併狀態檢查

請搜尋方法：

```csharp
AddSubjectStatusIfNotExists
```

確認它可以處理新的狀態文字：

```text
非課規科目
```

如果方法是一般化處理，例如：

```csharp
if (!list.Contains(s))
    list.Add(s);
```

則不需要大改。

請保留既有轉換：

```csharp
if (s == "尚未補修")
    s = "可補修";
```

如果目前已有：

```csharp
if (s == "成績不採計")
    s = "不採計";
```

可以保留。

請不要新增：

```csharp
if (s == "非課程規劃表課程")
    s = "非課規科目";
```

因為本次狀態輸出應在主判斷區塊明確輸出 `非課規科目`。

## 九、測試案例

請至少檢查以下案例。

### 1. 只有可重修

條件：

```text
狀態 = 可重修
成績科目級別重複 != 不重複採計
非課程規劃表課程 != 非課程規劃表課程
```

預期：

```text
可重修
```

---

### 2. 只有可補修

條件：

```text
狀態 = 尚未補修
成績科目級別重複 != 不重複採計
非課程規劃表課程 != 非課程規劃表課程
```

預期：

```text
可補修
```

---

### 3. 只有不採計

條件：

```text
成績科目級別重複 = 不重複採計
狀態不是 可重修 / 尚未補修
非課程規劃表課程 != 非課程規劃表課程
```

預期：

```text
不採計
```

---

### 4. 只有非課規科目

條件：

```text
狀態 = 已取得
非課程規劃表課程 = 非課程規劃表課程
成績科目級別重複 != 不重複採計
學分數 = 0
```

預期：

```text
非課規科目
```

---

### 5. 狀態是已修，不可輸出非課規科目

條件：

```text
狀態 = 已修
非課程規劃表課程 = 非課程規劃表課程
```

預期：

```text
不輸出非課規科目
```

說明：

```text
本次只接受 狀態="已取得"。
```

---

### 6. 可重修 + 不採計

條件：

```text
狀態 = 可重修
成績科目級別重複 = 不重複採計
```

預期：

```text
可重修、不採計
```

---

### 7. 可補修 + 不採計

條件：

```text
狀態 = 尚未補修
成績科目級別重複 = 不重複採計
```

預期：

```text
可補修、不採計
```

---

### 8. 不採計 + 非課規科目

條件：

```text
狀態 = 已取得
成績科目級別重複 = 不重複採計
非課程規劃表課程 = 非課程規劃表課程
```

預期：

```text
不採計、非課規科目
```
