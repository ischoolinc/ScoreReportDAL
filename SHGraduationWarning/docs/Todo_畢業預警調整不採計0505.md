# 目標

修改 `frmMain.cs` 的畢業預警報表資料流：

1. 新增「不採計」科目屬性判斷。
2. 原本「可補修」判斷邏輯仍使用 XML 狀態 `尚未補修`。
3. 輸出到報表合併欄位 `科目N_狀態` 時，將 `尚未補修` 顯示為 `可補修`。
4. 不可影響原本「可重修 / 可補修」判斷邏輯。
5. 修改完成後，請記錄在 `畢業預警調整0505.md`。

# 背景說明

目前畢業預警報表中，`科目1_狀態`、`科目2_狀態`... 來源是 `GrandCheckReport` XML 裡的 `<科目>` 節點。

原本只處理：

```csharp
xmlRuleS.GetAttribute("狀態") == "尚未補修"
||
xmlRuleS.GetAttribute("狀態") == "可重修"
````

其中：

* `尚未補修` 在邏輯上代表「可補修」。
* 但原本輸出到報表時會顯示 `尚未補修`。
* 這次要改成輸出顯示 `可補修`。

這次新增第三種科目屬性：

```csharp
xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計"
```

此狀態輸出到 `科目N_狀態` 時顯示：

```text
不採計
```

# 修改位置 2：替換為新版科目屬性處理邏輯

請將該 foreach 內的判斷邏輯調整為以下概念。

重點：

1. `尚未補修` 判斷不變。
2. `可重修` 判斷不變。
3. 新增 `成績科目級別重複 == "不重複採計"`。
4. 寫入 `rs.dicRetake` 前，複製 `XmlElement`，不要直接修改原始 XML。
5. 報表用的 `狀態` 屬性要改成合併後文字。
6. 同一個 `科目名稱_科目級別` 已存在時，只合併 `狀態`，不要覆蓋其他欄位，避免影響原本資料來源。

建議程式碼：

```csharp
// 處理科目屬性：可補修、可重修、不採計
foreach (XmlElement xmlRuleS in xmlRule.SelectNodes("科目"))
{
    // 原本邏輯：學分數 = 0 不列入報表科目清單
    if (xmlRuleS.GetAttribute("學分數") == "0")
        continue;

    string status = xmlRuleS.GetAttribute("狀態");

    // 判斷邏輯維持原本：尚未補修代表可補修
    bool isCanMakeup = status == "尚未補修";
    bool isCanRetake = status == "可重修";

    // 新增：不採計
    bool isNotIncluded = xmlRuleS.GetAttribute("成績科目級別重複") == "不重複採計";

    // 三種科目屬性都不是，就不輸出到科目狀態欄位
    if (!isCanMakeup && !isCanRetake && !isNotIncluded)
        continue;

    string sKey = xmlRuleS.GetAttribute("科目名稱") + "_" + xmlRuleS.GetAttribute("科目級別");

    // 複製一份，避免修改原始 GrandCheckReport XML
    XmlElement subjectElement = xmlRuleS.CloneNode(true) as XmlElement;

    List<string> statusList = new List<string>();

    if (isCanRetake)
        statusList.Add("可重修");

    if (isCanMakeup)
        statusList.Add("可補修");

    if (isNotIncluded)
        statusList.Add("不採計");

    // 輸出到報表的 科目N_狀態
    subjectElement.SetAttribute("狀態", string.Join("、", statusList.ToArray()));

    if (!rs.dicRetake.ContainsKey(sKey))
    {
        rs.dicRetake.Add(sKey, subjectElement);
    }
    else
    {
        // 同一科目名稱 + 科目級別 已經存在時，只合併狀態，不覆蓋其他資料
        XmlElement existElement = rs.dicRetake[sKey];

        List<string> mergedStatusList = new List<string>();

        AddSubjectStatusIfNotExists(mergedStatusList, existElement.GetAttribute("狀態"));
        AddSubjectStatusIfNotExists(mergedStatusList, subjectElement.GetAttribute("狀態"));

        existElement.SetAttribute("狀態", string.Join("、", mergedStatusList.ToArray()));
    }

    // 整理符合規則的科目與級別
    if (!rs.dicRetaleRelate.ContainsKey(Rule))
        rs.dicRetaleRelate.Add(Rule, new List<string>());

    if (!rs.dicRetaleRelate[Rule].Contains(sKey))
        rs.dicRetaleRelate[Rule].Add(sKey);
}
```

# 修改位置 3：新增輔助方法

請在 `frmMain.cs` 的 `frmMain` class 裡新增以下 private static method。

建議放在其他 private helper method 附近，不要放到 method 裡面。

```csharp
/// <summary>
/// 將科目狀態加入清單，避免重複。
/// 注意：判斷邏輯仍使用「尚未補修」，但輸出報表時顯示為「可補修」。
/// </summary>
private static void AddSubjectStatusIfNotExists(List<string> statusList, string statusText)
{
    if (string.IsNullOrWhiteSpace(statusText))
        return;

    string[] items = statusText.Split(
        new string[] { "、", "," },
        StringSplitOptions.RemoveEmptyEntries);

    foreach (string item in items)
    {
        string status = item.Trim();

        if (status == "尚未補修")
            status = "可補修";

        if (!statusList.Contains(status))
            statusList.Add(status);
    }
}
```

注意：

* 方法名稱使用 `AddSubjectStatusIfNotExists`，避免與其他既有方法名稱衝突。
* 如果專案 C# 版本不支援 `string.IsNullOrWhiteSpace`，請改成：

```csharp
if (string.IsNullOrEmpty(statusText) || statusText.Trim() == "")
    return;
```

但如果專案原本已有使用 `string.IsNullOrWhiteSpace`，則保持不變即可。

# 修改後資料流應為

```text
GrandCheckReport XML
    ↓
畢業規則
    ↓
科目
    ↓
判斷：
    狀態 == 尚未補修
    或 狀態 == 可重修
    或 成績科目級別重複 == 不重複採計
    ↓
學分數 = 0 則排除
    ↓
建立報表用 subjectElement
    ↓
狀態轉換：
    尚未補修 → 可補修
    可重修 → 可重修
    不重複採計 → 不採計
    ↓
同科目名稱 + 同科目級別：
    只合併狀態
    不覆蓋修課學年度、修課學期、學分數等原資料
    ↓
輸出到：
    科目1_狀態
    科目2_狀態
    ...
```
